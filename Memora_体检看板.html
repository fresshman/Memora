三、差距看板（按优先级）

P0 阻断项（不修必翻车）

P0模型路径布局不匹配

snapshot_download 返回路径被丢弃；发现/转换/文件名三处都要改为基于真实路径。

P0依赖缺失且未锁版本

补 llama-cpp-python、langchain-community、bs4、modelscope；出 lock 文件与 check_env 自检。

P0GGUF 与引擎须打包机预置

联网机转好 Q4_K_M 并跑通一次推理；优先随包分发 llama-server.exe 走 OpenAI 兼容接口，绕开 Python 绑定编译。

P0推理参数修正

n_gpu_layers 默认 0；n_ctx 默认 32768/65536 + KV q8；截断按 token 与 n_ctx 联动。

P0语音三件套随包

whisper-cli + ggml-base.bin + ffmpeg，跨平台二进制判断。

P0离线开关真正生效

下载前检查 ENFORCE_OFFLINE；注入 HF_HUB_OFFLINE / MODELSCOPE_OFFLINE；抓包审计 import 期外联。

P0干净虚拟机断网验收

无 Python/Node/编译器环境全流程录屏，是离线交付的唯一验收标准。

P1 竞赛硬核

P1真正的 RAG

本地 bge-small-zh + faiss-cpu 分片检索、引用溯源、跨历史会话问答；对话加密持久化（sentence-transformers 已装未用）。

P1评测集 + 消融实验

50-100 条标注样本；待办 F1 / 信息召回 / 风险召回 / 幻觉率 / CER / 延迟内存；1.7B·4B·MiniCPM 对比；长上下文 vs RAG、ctx、KV 量化消融。

P1Agent 含量

JSON schema/grammar 结构化输出、SSE 流式、待办-风险二次校验、per-call max_tokens 打通。

P1隐私口径修正

口令派生密钥或改称静态加密；清空覆盖 exports/logs；日志脱敏；新增 PII（手机号/证件/姓名）掩码。

P1解析器真实样本回归

三平台真实导出脱敏样本入仓库，覆盖系统消息/撤回/引用/多格式。

P2 工程与材料

P2离线分发与桌面化

PyInstaller spec 或 python-embedded；前端静态导出由后端托管；start.bat / doctor 自检；wheelhouse 与 sha256。

P2竞赛材料

零外联自证录屏、性能配置矩阵、白皮书、答辩 PPT、演示视频、竞品（云端妙记类）对比。
